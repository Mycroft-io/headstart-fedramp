# headstart-fedramp
Headstart 20x: reads an ISO 27001 Statement of Applicability or a SOC 2 report and shows how far it gets you toward FedRAMP 20x Class B, C or D. Maps the 46 Key Security Indicators to Annex A and the Trust Services Criteria, lists the FedRAMP rules with no equivalent, and exports a work plan. Runs entirely in the browser.
